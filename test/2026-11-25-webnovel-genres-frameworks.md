# 中国网文题材体系与创作框架验收

## 目标与成功标准

面向中国网文作者补齐「男生 / 女生」双频道题材体系、连载风向（番茄快节奏 / 起点长线精品 / 晋江人设情感 / 盐选爆款短篇）、热门流派·人设·情节标签组合，以及建书后自动落盘的 12 套七维题材世界观框架、本书网文连载总纲（`AGENTS.md`）与工作台垂类技法芯片；同时完成单次暂存目录原子建书、契约单一真源去重、首屏冷词典拆包、锁序无死锁并发验证与 Unicode 码点截断加固。

## 环境

Windows，Electron，简体中文与英文。界面验收探针使用隔离临时 `userData`、1200×860 视口与默认 14px UI 字号。

## 步骤与命令

- 执行 `pnpm typecheck`、`pnpm lint:boundary`、`pnpm lint:i18n` 与 `pnpm build`（含首屏应用 JS 与多语言体积预算校验）。
- 运行 `pnpm vitest run` 覆盖契约、渲染层、锁序并发与磁盘原子落盘集成测试套件。
- 启动无头 Electron 界面验收探针，依次验证长篇男频、长篇女频、爆款短篇开书配置与深色工作台技法向导并生成截图。

## 结果

- 类型检查、边界检查、多语言检查、生产构建与性能预算（`Renderer application JS: 1,234,588 B < 1,235,000 B`）全部通过。
- 相关测试套件全部通过：长篇与短篇建书均在 Core 暂存目录 `rename` 前单次原子初始化网文 `AGENTS.md`；`LongProjectStore` 双层锁序与 `FolderCatalogStore.mutate` 并发调用无死锁；`portableBookSchema` 同步契约与 `SHORT_BOOK_GENRES` 完全对齐；输入单行清洗与 10,000 码点安全截断全部生效。
- 界面探针截图归档至 [2026-11-25-webnovel-genres-frameworks](./2026-11-25-webnovel-genres-frameworks/)，浅色与深色主题下布局、选中态、标签计数与蓝图预览均无溢出。

## 未覆盖与后续

- 真实商业大模型在不同网文流派下的多章连载质感与读者追读数据，需结合实际密钥与连载样章进一步实测。
