# Writer 1.7.0 Windows x64 本地重打包

## 目标与成功标准

用包含订阅登录和账号管理修复的 1.7.0 替换本地 0.1.6 安装包，核对包内版本、更新清单和重开状态。

## 环境

Windows x64，Electron 42.5.0，两个 package.json 的版本均为 1.7.0。订阅复查使用独立临时资料目录。

## 步骤与命令

运行 `pnpm pack:win --skip-verify`。使用 `tools/release-files.mjs` 重算安装包大小和 SHA-512，与 latest.yml 比对。解压 blockmap 后核对所有分块的总字节数。
运行 `node apps/desktop/scripts/subscription-accounts-probe.mjs apps/desktop/.scratch/repack-1.7.0-screens --packaged`。

## 结果

安装包 106,863,747 字节，SHA-256 为 `dd741791a3750d0ba17accfa05ba0640700f97a63618f0c1418325ce6906675e`。包内 Writer.exe 文件版本为 1.7.0，首次启动、重开和包内文件校验通过。
打包版读到九个平台的登录入口、18 个模拟账号、各平台选定的主账号和缓存模型。移除账号后的重开验证通过。本地 release 目录已替换为 1.7.0 产物。
