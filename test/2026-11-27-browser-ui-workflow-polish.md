# 浏览器界面设计与核心操作逻辑优化验收

## 目标与成功标准

通过内置浏览器对长短篇创作工作台、6 角色长篇编剧室、新建书籍与网文定位管理进行深度巡检，修复发现的侧栏折叠死锁、编辑器弹层重叠与越界、只读页签状态矛盾、编剧室 i18n 漏译与自动抽卡摘要不一致、禁用主按钮对比度及新建/定位弹窗交互缺陷，并完成端到端复验与构建预算校验。

## 环境

Windows，Vite + 真实存储服务（`FolderCatalogStore` / `LongWorkspaceService` / `MysteryWorkspaceService`），内置 Chromium 浏览器（`1280×840` 与 `1000×680`，浅色与深色主题）。

## 步骤与命令

- 浏览器实测巡检与两轮回归复验（0 控制台报错、0 失败请求）。
- 执行 `pnpm typecheck`、`pnpm lint:boundary`、`pnpm lint:i18n`、ESLint、Prettier、定向 Vitest（`messages.test.ts` / `BookPositioningPanel.test.ts` / `LongWorkspaceEditor.view-mode.test.ts`）与 `pnpm build`。

## 结果

- **侧栏折叠防死锁（P0）**：双侧栏收起时，长篇编辑栏左上角自动提供 `展开左侧栏` 按钮，点击可稳定恢复左栏。
- **弹层互斥与目录防越界（P1）**：`文档目录` 贴合编辑栏内边界不跨越左侧分隔线，且与 `查找文字`、`全书搜索`、`笔记与记忆` 全面互斥。
- **只读页签一致性（P1）**：`章末状态` / `下一章接续包` 展示专属空态文案（`暂无章末状态` / `暂无下一章接续包`），底栏隐藏矛盾的 `自动保存开启`，工具栏 `替换` 按钮同步禁用。
- **编剧室体验（P0/P1/P2）**：补齐 `subagentsUseThePrimaryAgentSModelByDefault` 中英文文案；`countMode === "auto"` 摘要统一显示 `抽卡 · 自动`；`评估助手` 模型配置使用独立无障碍标签；浅色主题下禁用的 `保存智能体团队` 按钮改为明确置灰态。
- **新建与定位弹窗（P1）**：空书名提交改为输入框内联红框校验并自动聚焦；短篇节奏标题改为 `短篇节奏与篇幅风向`；`1000×680` 深色定位页底部留白充足不裁切。
- 全量门禁与生产构建预算通过（`Renderer application JS: 1,222,257 B`），代表性截图归档至 [2026-11-27-browser-ui-workflow-polish](./2026-11-27-browser-ui-workflow-polish/)。
