# Google 浏览器登录的发行配置

## 目标与成功标准

发行版提供 Google OAuth 桌面客户端配置。新用户可以获取链接、在浏览器授权并回到 Writer 保存账号，无需设置环境变量。

## 环境

Windows x64，隔离的 Writer 资料目录，模拟 Google OAuth 与订阅服务。两组占位客户端配置只在测试构建时传入。

## 步骤与命令

- 执行 90 项订阅测试、类型、边界、多语言、改动文件 ESLint 和 Prettier。
- 用两组占位 OAuth 桌面客户端执行 `pnpm pack:win --skip-verify`。在子进程清空旧的运行时配置，再运行九平台账号探针。
- 核对链接和令牌请求使用构建时的客户端配置。验证 PKCE、浏览器回调、保存、重复登录、取消、拒绝和过期。

## 结果

- 两个 Google 入口均可打开、复制链接和完成模拟授权。客户端参数在 Main 中使用，浏览器链接没有客户端密钥。登录回调后账号可见，九平台账号重开和首次启动冒烟通过。[测试截图](2026-11-28-google-release-login/screenshots/)
- 源码提交 `be75bc7` 已推送到 GitHub `main`。测试包归档在临时目录。

## 未覆盖与后续

GitHub 发布配置尚无 Writer 获准使用的 Google OAuth 客户端，真实 Google 授权与新正式包仍待验证。现有 0.1.7 安装包早于本次修改。
