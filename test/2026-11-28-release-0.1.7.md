# Writer 0.1.7 发布验收

## 目标与成功标准

官网目录刷新后保留默认模型 ID，订阅模型和账号管理随 Windows x64 版发布。GitHub Release 与自动更新清单均指向经过验收的安装包。

## 环境

2026-11-28，Windows x64，Electron 42.5.0。九平台账号探针使用隔离资料目录和模拟上游。

## 步骤与命令

- 运行 `pnpm typecheck`、ESLint、边界、多语言、订阅和官网 Gemini 定向测试。
- 运行 `pnpm pack:win --skip-verify`，核对包内版本、首次启动、重开、blockmap、SHA-512 和 SHA-256。用最终打包版复验账号流程。
- 核对 GitHub 标签和发布附件，从公开下载地址复验安装包与更新清单，检查远端 `main` 上的 `update.json`。

## 结果

- 官网 Gemini 模型刷新回归通过，已选默认模型的 ID 保持且停用状态得到保留。包括 Google OAuth 本机配置检查在内的 94 项定向测试，以及 33 项更新与配置测试通过。
- GitHub 推送拦截了两处内置 Google OAuth 密钥。移除后重新提交和打包，包内核查通过。两个 Google 登录入口在模拟本机客户端配置下可正常完成回调，九平台 10 条登录路径和 18 个模拟账号通过。[最终截图](2026-11-28-release-0.1.7/screenshots/)
- 0.1.7 安装包首次启动与重开通过。公开安装包为 106,866,814 字节，SHA-256 为 `04860fac8346ed06cc5cfa461b82d8adef71b1926f2d1195d212f3ae4991d611`。公开附件与本地一致。[GitHub Release](https://github.com/Minglink/Writer/releases/tag/v0.1.7)
- 发布标签指向 `e11d16c`。清单提交 `f7bb759` 已推送，公开的 `update.json` 与该提交一致。

## 未覆盖与后续

全量 Vitest 运行中 7,335 项通过、19 项跳过，1 项 Windows 文件锁测试遇到 `realpath UNKNOWN`，相关测试单独复跑通过。Google OAuth 使用模拟客户端配置复验。此前的本地 1.7.0 需要下载安装包切换到 0.1.7。
